# Progress Log

## Learnings
(Patterns discovered during implementation)
- `set +e` at top + explicit `exit 0` at bottom is the cleanest way to make a git hook that never fails
- awk `gsub(/\\/, "\\\\"); gsub(/"/, "\\\"")` handles JSON string escaping inside filenames
- `git diff-tree --no-commit-id -r --name-only HEAD` lists files changed in last commit; returns empty for initial commit (no parent), yielding `[]` which is valid
- `basename "$REMOTE_URL" .git` strips both the path prefix and .git suffix from HTTPS or SSH remote URLs

- Added `install_obsidian()` function: prompts for vault path, writes env vars to ~/.bashrc (idempotent via grep+sed), exports vars, runs vault-scaffold.sh / claude-md-block.sh / install-hooks.sh

- Idempotency: `grep -qF "export VAULT_PATH=" ~/.bashrc` + `sed -i` replaces existing value; only appends when missing
- Vault-scaffold.sh already prints Windows UNC path and GitHub instructions — no duplication needed
- Files changed: install.sh (modified), PRD.md (task marked [x])
- Learnings for future iterations:
  - When adding a new independent flag alongside existing mode flags, guard interactive prompts with `&& [ "$NEW_FLAG" -eq 0 ]` to prevent them from firing when only the new flag is set
